### Your AI-powered networking assistant for smarter, faster, and more memorable coffee chats.

Coffee Copilot helps you capture, summarize, and follow up on meaningful conversations — without ever opening a notes app.  
It transcribes your chats, highlights the key points, and even generates context-aware follow-up suggestions, all powered by **Genesys Cloud CX APIs**, **Cohere**, and **AssemblyAI**.

---

## 🏅 Award & Recognition
- 🥇 **Winner — Best Hack Using Genesys**, *Hack the North 2023*
- Recognized for outstanding integration of **Genesys Cloud CX API** to enhance real-time human interactions.

---

## 💡 Inspiration
Networking is crucial for students, founders, and professionals — but keeping track of every chat is nearly impossible.  
We’ve all left events with scattered notes, half-remembered names, and missed opportunities.  
**Coffee Copilot** was built to fix that: a digital co-pilot that listens, remembers, and helps you reconnect more meaningfully.

---

## 🎯 What It Does
- 🎙 **Transcribes conversations** in real time  
- 🧠 **Summarizes** discussion points and action items  
- 💬 **Suggests personalized follow-ups** based on context  
- 🪄 Integrates with **Genesys Forms** to structure feedback or intake data

---

## 🛠️ How We Built It

### Backend
- **Python + FastAPI** for API and CRUD endpoints  
- **Cohere (Coral model)** for summarization and prompt generation  
- **AssemblyAI** for speech-to-text and speaker diarization  
- **CockroachDB** to store user and conversation data  

### Frontend
- **Next.js** for a responsive web interface  
- Real-time updates via **WebSocket** connections  
- Clean, minimal dashboard for reviewing summaries and transcripts  

---

## ⚔️ Challenges We Faced
- Managing large audio blobs between frontend and backend under time constraints  
- Changing direction mid-hackathon to focus on conversational memory  
- Optimizing latency between transcription and summarization pipelines
